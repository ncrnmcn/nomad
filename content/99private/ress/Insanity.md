# Temporary & Indefinite Insanity Tables

---

## Temporary Insanity Type

|     d% | Type       | Duration        |
| -----: | ---------- | --------------- |
|  01–80 | Short-term | 1d10 + 4 rounds |
| 81–100 | Long-term  | 1d10 × 10 hours |

---

## Short-Term Temporary Insanity Effects

|    d% | Effect                                                                                                                        |
| ----: | ----------------------------------------------------------------------------------------------------------------------------- |
| 01–20 | Character faints (can be awakened by vigorous action taking 1 round; thereafter, character is shaken until duration expires). |
| 21–30 | Character has a screaming fit.                                                                                                |
| 31–40 | Character flees in panic.                                                                                                     |
| 41–50 | Character shows physical hysterics or emotional outburst (laughing, crying, etc.).                                            |
| 51–55 | Character babbles in incoherent rapid speech or in logorrhea (a torrent of coherent speech).                                  |
| 56–60 | Character gripped by intense phobia, perhaps rooting her to the spot.                                                         |
| 61–65 | Character becomes homicidal, dealing harm to nearest person as efficiently as possible.                                       |
| 66–70 | Character has hallucinations or delusions (GM discretion).                                                                    |
| 71–75 | Character gripped with echopraxia or echolalia (imitates nearby speech/actions).                                              |
| 76–80 | Character gripped with strange or deviant eating desire (dirt, slime, cannibalism, etc.).                                     |
| 81–90 | Character falls into a stupor (fetal position, oblivious to surroundings).                                                    |
| 91–99 | Character becomes catatonic (can stand; no will or interest; may be led to simple actions).                                   |
|   100 | Roll on **Long-Term Temporary Insanity Effects**.                                                                             |

---

## Long-Term Temporary Insanity Effects

| d% | Effect |
|----:|--------|
| 01–10 | Compulsive rituals (washing hands, praying, pacing rhythms, checking weapons, etc.). |
| 11–20 | Hallucinations or delusions (GM discretion). |
| 21–30 | Paranoia. |
| 31–40 | Severe phobia (refuses approach except on successful DC 20 Will save). |
| 41–45 | Aberrant sexual desires (exhibitionism, nymphomania/satyriasis, teratophilia, necrophilia, etc.). |
| 46–55 | Attachment to a “lucky charm”; cannot function without it. |
| 56–65 | Psychosomatic blindness, deafness, or loss of limb use. |
| 66–75 | Uncontrollable tics or tremors (–4 penalty to physical rolls). |
| 76–85 | Amnesia (memories of intimates lost first; Knowledge skills useless). |
| 86–90 | Reactive psychosis (incoherence, delusions, aberrant behavior, hallucinations). |
| 91–95 | Loss of ability to communicate via speech or writing. |
| 96–100 | Catatonia (can stand, no independent action). |

## Duration References

- **Short-Term:** 1d10 + 4 combat rounds  
- **Long-Term:** 1d10 × 10 game hours  
- **Indefinite:** 1d6 game months

## Personality Fallout Traits

| Trait | Description |
|------|-------------|
| Cold | Not moved by emotional appeals or social bonds. |
| Haunted | Lost in reverie, reliving past horrors. |
| Obsessed | Enthralled by a single activity, person, or ideology. |
| Paranoid | Imagines danger everywhere; trusts no one. |
| Reckless | Little regard for personal safety or interests. |
| Soft | Becomes sentimental, passive, gentle. |
| Unstable | Volatile emotions; rage, despair, impulsivity, freezing. |
| Vicious | Seeks opportunities to hurt others. |
